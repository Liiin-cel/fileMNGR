# fileMNGR
эта консольная утилита, которая будет сканировать указанную папку, автоматически сортировать файлы по типам в нужные папки, и может делать архивные копии важных проектов

АРХИТЕКТУРА:
Архитектура состоит из трех модулей:
* Конфигуратор — загружает правила сортировки.
* Сканер — анализирует файлы в указанной папке.
* Организатор — перемещает файлы в целевые директории и ведет лог событий.
