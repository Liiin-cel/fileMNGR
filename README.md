# fileMNGR — Консольный файловый менеджер и автоматический сортировщик

**Область разработки:** Автоматизация управления файлами и организация данных на локальном диске.

## Постановка задачи

### 1. Актуальность
При ежедневной работе за компьютером в пользовательских директориях (например, «Загрузки», «Рабочий стол», рабочие папки проектов) быстро накапливается большое количество разнородных файлов: документы, архивы, изображения, исходный код и медиафайлы. Ручная сортировка и поддержание порядка занимают много времени, приводят к дублированию данных и усложняют поиск нужной информации. Автоматизация этого процесса по настраиваемым правилам позволяет поддерживать чистоту файловой структуры без постоянных ручных действий.

### 2. Цель проекта
Разработать консольное приложение на языке C++ для автоматической сортировки файлов по категориям и базового управления файловой системой с гибкой настройкой правил через пользовательский конфигурационный файл.

### 3. Задачи проекта
1. Спроектировать архитектуру консольного файлового менеджера с разделением на модули (основная логика, конфигурация, логирование).
2. Реализовать чтение и редактирование правил сортировки через внешний файл напрямую из интерфейса программы.
3. Разработать алгоритм автоматического распределения файлов по целевым папкам на основе их расширений.
4. Реализовать базовые операции навигации и управления файлами/директориями в консоли.
5. Внедрить модуль логирования для записи всех выполненных операций и ошибок с привязкой ко времени.

### 4. Основной функционал
1. Автоматическая сортировка файлов: сканирование выбранной директории и перенос файлов в соответствующие подпапки согласно правилам.
2. Управление конфигурацией: просмотр текущих правил сопоставления «расширение → папка», добавление новых правил и изменение существующих прямо через консольное меню.
3. Журналирование действий: сохранение истории всех запусков, перемещений и ошибок в лог-файл.

### 5. Целевая аудитория
- Студенты и разработчики, у которых в рабочих директориях накапливаются учебные материалы, архивы, исходники и отчёты.
- Обычные пользователи ПК, желающие одним запуском программы наводить порядок в папке «Загрузки» или на «Рабочем столе» по собственным правилам.


## Структура проекта
- `mngrf.cpp` — точка входа и основной цикл консольного меню.
- `Logger.hpp` / `Logger.cpp` — модуль логирования событий с отметкой времени.
- `config.txt` — файл пользовательских правил сортировки.
- `docs/` — техническая документация и описание архитектуры проекта.
